
# 💬 SLANG DECODER - Social Media Slang Normalization 🚀

🔥 Transform internet slang into proper English instantly with AI-powered text normalization!

✨ What is SlangDecoder?
An interactive web application that decodes social media slang and translates it into standard English using NLP preprocessing and intelligent dictionary mapping. Say goodbye to confusing abbreviations! 🎯
🛠️ Tech Stack

🐍 Python - Core programming language
⚡ Streamlit - Interactive web framework
📊 Pandas - Data manipulation & analysis
📁 CSV Database - 1,445+ slang entries
🔄 Real-time Engine - Instant text normalization
